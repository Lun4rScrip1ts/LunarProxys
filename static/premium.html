BEFORE CHECKOUT

How Premium will work

How will payment work?

The Premium button is ready for a secure hosted checkout. A payment provider will be connected later so the site never handles card details directly.

How will Premium activate?

After a successful payment, the provider will notify Lunar's server. The server will verify the payment and then mark the account as Premium.

Can I cancel?

The final checkout provider will control subscription cancellation and billing management. The account page can show the current Premium status.
